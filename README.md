# MysteryBoxQR

QRコードを読み取ると、そのQRコードに割り当てた単語を表示するページです。

- 表示ページ: `index.html`（QRコードのURLの `#` 以降が合言葉）
- 管理ページ: `admin.html`（単語の登録、QRコード画像と `words.json` の書き出し）
- `words.json`: 単語と画像の情報を合言葉で暗号化したもの。合言葉を知らないと読めません。
- `img-*.bin`: 暗号化した画像ファイル

## 単語・画像を追加・変更する

1. `admin.html` を開き、単語や画像を設定して「公開用ファイルを書き出す」
2. 書き出した `words.json` と `img-*.bin` をこのリポジトリにアップロード（`words.json` は上書き）
3. 反映後、QRコードを印刷

合言葉の控え（控えファイル）はリポジトリに入れないでください。
